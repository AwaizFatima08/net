# Prep Simulator for NET

A free Android app by [HomiLabs](https://homilabs.org) for students preparing for the NUST Entry Test (NET): 20 full-length timed NET-Engineering mocks (Mathematics 100, Physics 60, English 40), subject-wise practice for Mathematics, Physics, English, Chemistry, Biology and Quantitative Mathematics, every answer explained, and a guide to the NET papers, admission rules, merit formula and test day. Independent practice material, not affiliated with NUST.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Question bank: `content/bank/` (5,304 original questions, every key independently re-solved: `docs/blind-check.md`), built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, live at https://net.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
