# Question bank format

Source files: `content/bank/<section>/<topic>.jsonl` (sections `math`, `physics`, `english` for the mocks and practice; `chemistry`, `biology`, `quant` practice only; a topic may split
across writers as `<topic>-2.jsonl`, `<topic>-3.jsonl`). One JSON object per line, UTF-8. Topics, id prefixes, targets
and scope are in `content/blueprint.json` (generated by `tool/make_blueprint.py`).

```json
{"id":"mf-t0001","pool":"test","level":2,"stem":"...","options":["...","...","...","..."],"answer":1,"explanation":"..."}
```
| Field | Rule |
|---|---|
| `id` | `<prefix>-t0001` for the mock pool, `<prefix>-p0001` for practice; prefix is in the blueprint |
| `pool` | `test` (goes into the 20 mock papers of that subject) or `practice` (topic practice only). Never reuse an item across pools |
| `level` | 1 easy, 2 medium, 3 hard. Aim for about 30 / 50 / 20 % |
| `options` | exactly 4 strings (single answer, options A-D) |
| `answer` | index 0-3 of the correct option. Spread evenly; never a pattern |
| `explanation` | the worked solution: key steps with the numbers, then why the most tempting wrong option is wrong. 2-6 sentences |
| `table` | optional: rows of strings, first row is the header. Data tables only |

Plain Unicode maths only (x², √, π, ≤, ≥, ≠, →, ⇌, Δ, θ, ω, λ, μ, ₂ subscripts, ⁻ superscripts, ½, fractions as a/b
with brackets where needed: (x + 1)/(x − 2)). No LaTeX, no Markdown, no images: a question that needs a diagram must
describe the figure fully in words or be written differently.

## Reading passages (english/reading only)
A passage is its own line, written before its questions:
```json
{"type":"set","id":"er-s001","title":"The Indus river dolphin","text":"Passage text, 180-260 words, original."}
```
Each question of that passage carries `"set":"er-s001"`. A passage has exactly 3 questions, all in the same pool.
Set ids: `er-s001`… for passages whose questions are in the mock pool, `er-q001`… for practice passages.

## Short stock stems
Stems such as "Choose the correct sentence." may repeat; the duplicate check then compares the options too.
English vocabulary stems name the task in full, e.g. "Choose the word closest in meaning to: METICULOUS".
